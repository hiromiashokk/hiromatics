# Hiromatics

Hiromatics is a browser-based interactive learning site created by Hiromi for Grade 7 math. It presents textbook-style chapters as playable web pages, with support for quizzes, draggable elements, and visual learning interactions.

## Project Structure

- `index.html` — Main landing page with navigable chapter cards.
- `shared.css` — Common styles used across the site.
- `shared.js` — Shared JavaScript utilities and behavior.
- `ch01.html` through `ch15.html` — Chapter pages with interactive content.
- `ch05_learn.png` — Supporting image asset for chapter 5.

## Features

- Chapter selection from two parts on the index page.
- Visual chapter cards with titles and descriptions.
- Shared styling and JavaScript for a consistent experience.
- Progress tracking via the page UI.

## Usage

1. Open `index.html` in a modern browser.
2. Select any chapter card to navigate to that chapter.
3. Each chapter page contains interactive elements and exercises.
